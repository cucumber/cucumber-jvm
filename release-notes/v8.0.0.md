Cucumber-JVM v8.0.0
===================

It's been about five years since the last major version. 

Below we'll discuss some notable changes in v8.0.0 As always the full change log

can be found in [the usual place](../CHANGELOG.md).

Java 17 baseline
----------------

Jackson is now an opt-in dependency
-----------------------------------

Use JSpecify to declare nullability
-----------------------------------

Declare step definitions and hooks with minimal ceremony
--------------------------------------------------------

Support for registering individual glue classes
-----------------------------------------------

Support class filtering before class loading
---------------------------------------------

Support both DocString and DataTable arguments on steps
-------------------------------------------------------

Update skipped, pending and undefined colors
--------------------------------------------

Deprecated Cucumber-TestNG and Cucumber-JUnit
---------------------------------------------

Cucumber-Java8 currently no longer under consideration for deprecation
----------------------------------------------------------------------
